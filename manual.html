SANE Studio user manual

This copy of SANE Studio runs in your browser. The manual was written for the server version, so where it says files are uploaded to a session and deleted after 60 minutes, read instead: your recordings never leave this computer, the session lasts until you close or reload the tab, and the first visit downloads the engine (about 50 MB). Everything else, the screens, settings, charts and outputs, is the same.

This manual walks through SANE Studio from the first screen to the last download. Every button, setting, chart and message is covered, in the order you meet them. The screenshots come from the product itself, using the sample dataset that ships with it, so you can follow along on your own copy.

1About SANE Studio

SANE Studio takes EEG recordings and removes the subject-level biomarkers that can reveal a person's neurological condition, such as an elevated theta/beta ratio. You get the data back in the same file format you uploaded, so it can go into the same analysis pipeline as before.

SANE stands for Spectral Attribute Neutralization for EEG. For each person it measures two things that stay roughly constant across a recording: how much power each channel has in each frequency band (the spectral profile), and how the channels move together within each band (the spatial covariance). It then moves both onto a shared reference, so the profile that marks one person as different from the others is gone.

What changes and what stays

ChangedKept
Each subject's band-power profile per channel (delta, theta, alpha, beta, gamma), including the theta/beta ratioMoment-to-moment brain activity: event-related responses, oscillation bursts, ERD/ERS
Each subject's spatial fingerprint: the channel-to-channel correlations within each bandEvery event marker, with the same times and labels
Personal header fields such as name, birth date and recording date (optional, on by default)EOG, ECG, EMG, trigger and other non-EEG channels, bit for bit
File format, sampling rate, channel names, channel order and recording length
What SANE Studio is notSANE Studio neutralizes subject-level spectral and spatial biomarkers. It is not a complete anonymization tool. Individual traits outside those statistics, such as the exact frequency of a person's alpha peak, can remain in the data. Treat processed files as de-identified research data, not as anonymous data.

2Starting SANE Studio

If SANE Studio is hosted for you online, open its web address and skip to section 4. To run it on your own Windows computer, follow these steps.

What you need

  • Python 3.10 or newer (from python.org).
  • A modern browser: Chrome, Edge, Firefox or Safari.
  • Free memory of about twice the size of the recording you process. A one-hour, 64-channel recording at 1000 Hz needs roughly 2 GB.
  • Free disk space for working files. One session can use several GB while it is open.

Steps

  1. Open PowerShell. Press the Windows key, type PowerShell and open it.
  2. Go to the project folder.
    cd "E:\Brain signal work\sane-studio"
  3. Install the packages (first time only).
    pip install -r requirements.txt
  4. Choose where working files go. By default they go to the Windows temp folder on drive C:. If C: is small, point them at another drive:
    $env:SANE_DATA_DIR = "D:\sane_jobs"
  5. Start the server.
    python -m uvicorn app.main:app --port 8000
    Wait for the line Application startup complete. Leave this window open: closing it stops SANE Studio.
  6. Open the app. In your browser, go to http://localhost:8000. This manual is at http://localhost:8000/manual.
  7. Stop it when you are done. Click the PowerShell window and press Ctrl + C.
Next timeYou only need steps 1, 2, 4, 5 and 6. The packages stay installed.

3Files you can upload

SANE Studio reads continuous EEG recordings in five formats. Some formats are split across several files, and you need to upload all of them together. Upload them in one go, or drop the whole folder.

FormatUpload these filesYou get back
EDF / EDF+recording.edfrecording_sane.edf
BDF / BDF+ (Biosemi)recording.bdfrecording_sane.bdf
BrainVisionrecording.vhdr + recording.vmrk + recording.eegthe same three files with _sane added, in a zip
EEGLABrecording.set, plus recording.fdt if the recording has onerecording_sane.set (plus recording_sane.fdt if you uploaded a .fdt)
FIF (MNE / Neuromag)recording.fif or recording.fif.gz; for a split recording, every partrecording_sane_raw.fif

Things to know before you upload

  • Companion files are matched for you. A BrainVision header is paired with its marker and data files even if the files were renamed after recording. An EEGLAB .set is paired with the .fdt of the same name.
  • Different formats can share one session. You can upload EDF and BrainVision files together; each one comes back in its own format.
  • Recordings must be continuous. Files already cut into trials (epoched files) are refused. Upload the continuous recording.
  • Each recording needs at least two scalp EEG channels and at least 10 seconds of data.
  • The default upload limit is 1024 MB per session. An administrator can change it (section 17).

Files that look right but cannot be processed

Some files share an EEG extension but hold no EEG. SANE Studio recognizes them and tells you why it skipped them (section 15):

  • EyeLink eye-tracker files, which also end in .edf.
  • MEG-only .fif files, including "empty room" noise recordings with no person in the scanner.
  • Part 2 or later of a split .fif recording uploaded without part 1.
  • DataLad, git-annex or Git LFS placeholders: small text files that stand in for a recording that was never downloaded.
  • Damaged files, such as a BrainVision data file cut off during copying, or a file whose values are physically impossible for EEG.
  • Recordings whose scalp EEG channels contain no signal at all.

4The four screens

Working with SANE Studio always follows the same path. You can go back from the results to the settings as often as you like.

1 · Upload→2 · Review recordings→3 · Processing→4 · Results
  1. Upload: add your files, or try a sample dataset (section 6).
  2. Review recordings: check what SANE Studio found in each file, set subject IDs and choose settings (sections 7 and 8).
  3. Processing: a progress screen while SANE Studio works (section 9).
  4. Results: compare input and output, read the privacy report and download your files (sections 10 to 12).

The address bar shows a session code after the # sign, for example localhost:8000/#8f8a1406d407. Reloading the page, or opening that address again while the session is alive, brings you back to the same place.

6Screen 1: Upload

The drop zone

There are three ways to add files:

  • Drag and drop. Drag files, or a whole folder, from File Explorer onto the dashed box. The box turns teal while you hold files over it. Folders are searched, including their subfolders.
  • Choose files opens a file picker. Hold Ctrl to select several files, for example a .vhdr, .vmrk and .eeg together.
  • Choose folder uploads every supported file in a folder you pick, including subfolders.

The chips under the buttons list the accepted extensions. SANE Studio ignores files with other extensions, so dropping a folder that also holds spreadsheets or documents is fine.

While files upload, the title of the drop zone shows progress, for example Uploading 3 files · 45% of 167.3 MB. When the upload finishes, the Review screen opens.

Sample datasets

Click a card to start a session with that data, exactly as if you had uploaded it. Both run in a few seconds.

  • Resting EEG, depression study: three subjects, 64 EEG and 2 EOG channels, 250 Hz, EDF. Real recordings from OpenNeuro dataset ds003478 (public domain, CC0).
  • 128-channel motor task (synthetic): three subjects, Biosemi 128 channels plus Status, 256 Hz, BDF. Subject 3 carries an elevated theta biomarker, so you can watch SANE remove it.

What happens to your data

The panel on the right of the Upload screen is information only; it has no controls. It summarizes the process:

  1. Read: each recording is parsed with MNE-Python, and scalp EEG is separated from EOG, ECG, EMG and trigger channels.
  2. Neutralize: each subject's band power and channel relationships are moved to the reference.
  3. Return: you download the result in the format you uploaded.

Below the steps it lists the privacy promises (session deletion after 60 minutes, optional header stripping, the privacy report) and what is neutralized versus preserved.

Notes under the table tell you about files that were ignored, for example a .fdt without its .set, or a file that is not EEG at all.

Subject IDs

SANE Studio builds one correction per subject. Recordings with the same subject ID are treated as the same person: their statistics are combined, and in a group they count once toward the reference.

  • SANE Studio fills the ID in from the file name when it follows the BIDS style (sub-001_task-rest_eeg.edf gives sub-001). Otherwise it uses the file name.
  • Give recordings of the same person the same ID, for example two sessions of one patient.
  • Give different people different IDs. This matters when you mix files from different studies, which often reuse labels such as sub-01.
  • The number of different IDs decides whether a group (cohort) reference can be used. The Reference hint in the settings panel updates as you type.

8Neutralization settings

The panel on the right of the Review screen controls how SANE Studio processes the recordings. The defaults suit most uses: full strength, automatic spatial alignment, automatic reference, both switches on.

Strength α

A slider from 0 (off) to 1 (full) in steps of 0.05. Default: 1.00.

At 1, each subject's band power per channel is set exactly to the reference. At 0, with Spatial alignment on Auto, the output is identical to the input. Values in between move part of the way: at 0.5, a channel's power ends up halfway between its own value and the reference on a logarithmic scale.

Lower the strength only if you need to keep part of each subject's individual profile and accept that some of the biomarker remains. For privacy, use 1.

Spatial alignment

A second slider from 0 (keep channels) to 1 (full). It controls how far each subject's channel-to-channel correlations move onto the reference, which removes the spatial fingerprint. It does not affect removal of the spectral biomarker.

By default it is set to Auto, shown as Auto · full or Auto · off:

  • Auto · full when recordings are aligned to your own cohort. The cohort is a measured reference, and in our tests the output kept a brain-dynamics score of 0.92 to 0.99. In this mode spatial alignment follows the strength: at strength 0.5 it is also 0.5.
  • Auto · off when recordings are aligned to the built-in normative profile. The only spatial target there is a generic head model, and aligning to it rebuilds each channel largely from its neighbours, which costs much more of the signal.

Move the slider to choose a value yourself. The value then applies to every recording, and a Back to auto link appears under the slider to restore the automatic choice.

When to change spatial alignmentLower it toward 0 if your analysis reads individual channels, such as ERP amplitude at Pz, and you want every channel to keep its own signal. Raise it toward 1 for a single subject if removing the spatial fingerprint matters more than keeping each channel exactly as recorded.

Reference

The reference is the profile every subject is moved toward. Three buttons choose it:

ChoiceWhat it does
Auto (default)Uses your cohort when there are at least two different subject IDs among the ready recordings. Otherwise uses the normative profile.
CohortAlways uses the cohort average. With fewer than two subjects this is impossible, so the hint says the normative profile will be used instead.
NormativeAlways uses the built-in normative profile, even when several subjects are uploaded.

The cohort reference is the average of your subjects, built channel by channel. Each subject counts once, however many recordings they have. Channels are matched by name, ignoring upper and lower case and spaces, so slightly different montages still line up. This keeps the group's typical profile, so group-level analyses of the processed data stay meaningful.

The normative profile is a built-in typical spectral shape. Each channel keeps its own overall power and takes on the normative balance between bands.

The hint under the buttons tells you which reference will be used. Two cases are handled automatically during processing and reported in the results:

  • In a cohort, a recording whose channel names barely overlap with any other subject's (less than half of its channels) is matched to the normative profile instead. Without that, it would be compared only with itself and come back unchanged.
  • Within a cohort, a channel that only one subject has gets the cohort's average spectral shape at its own power level.

Normative spatial model

Two buttons decide what the spatial target looks like when a recording uses the normative profile and spatial alignment is above 0. Otherwise this setting has no effect, and it is shown dimmed.

ChoiceWhat it does
Head geometry (default)Models how signals spread across the scalp from the distance between electrodes. Positions come from the file, or are matched by channel name to the standard 10-05, Biosemi or EGI layouts. Channels without a known position keep their own relationships.
DecorrelatedTreats every channel as independent of the others. This removes the most spatial information and changes the signal the most.

Keep content outside 1–45 Hz

A switch, on by default. SANE Studio works on five bands: delta 1–4 Hz, theta 4–8 Hz, alpha 8–13 Hz, beta 13–30 Hz and gamma 30–45 Hz. With the switch on, slow drifts below 1 Hz and content above 45 Hz pass through the EEG channels unchanged. With it off, that content is removed from the processed EEG channels. Non-EEG channels are never touched either way.

At low sampling rates, bands above the recording's frequency limit are left out. Below about 100 Hz sampling there is no gamma band, and below about 70 Hz no beta band either.

Strip personal metadata

A switch, on by default. It removes identifying fields from the header of each output file:

FormatWhat is removed
EDF, BDFPatient identification becomes X X X X, recording identification becomes Startdate X X X X, and the start date and time become 01.01.85 00.00.00.
BrainVisionThe recording date and time stored in the marker file is removed.
EEGLAB, FIFSubject name, ID and sex are replaced, the experimenter field is replaced, and the measurement date becomes 1 January 2000. A birth date, if present, moves by the same amount, so age is kept.

Event times are stored relative to the start of the recording, so they stay correct. Turn the switch off only if you need the original dates in the output.

The Neutralize button

The button at the bottom of the panel starts processing. It names how many recordings will be processed, for example Neutralize 3 recordings. If no recording is ready, it reads No recordings can be processed and cannot be clicked.

Your goalSettings

9Screen 3: Processing

This screen has no controls. The bar fills as work progresses, the line under it says what is happening, and the five step labels light up in turn:

StepWhat happens
AnalyzeEach recording is read and its channels are sorted. Windows with amplifier saturation, spikes, flat signal, missing samples or BAD_ annotations are set aside. Band power and channel relationships are measured on the rest.
ReferenceThe cohort or normative reference is built, and one correction is computed per subject.
NeutralizeThe correction is applied to the whole continuous recording.
WriteThe output is written in the original format.
ReportThe before/after measurements are calculated and the downloads are packaged.

Most recordings take a few seconds to a minute. A 30-minute, 64-channel recording takes about half a minute on a typical laptop. You can leave the tab open and wait; the results open by themselves.

If one recording fails, the others are still processed, and the failed one is listed as skipped with its reason when you click Change settings. If every recording fails, you return to the Review screen with a message that names each file and its problem.

10Screen 4: Results

The recordings list

Each processed recording has one entry showing its format, file name, subject ID, number of EEG channels, and its theta/beta biomarker before and after (θ/β 0.88 → 0.39). The amber number is the input, the teal number the output. Click an entry to show that recording. The selected one is highlighted.

Download all (.zip) downloads one zip file (sane_outputs.zip) with every output file and the full report, SANE_REPORT.json.

Change settings returns to the Review screen with the same files. There you can change settings or subject IDs, add files, and run again. A new run replaces the previous outputs.

The recording header

The title is the file name. The chips under it show format, subject ID, channel count (EEG plus auxiliary channels), sampling rate, duration, number of events, and the reference used:

  • cohort reference · 3 subjects: aligned to the average of three subjects.
  • normative · kernel: normative profile, spatial model from head geometry.
  • normative · own-spatial: normative profile, and no electrode positions were found, so channel relationships stay as recorded.
  • normative · identity: normative profile with the Decorrelated spatial model.

An amber note under the chips appears when something about this recording is worth knowing. For example, it was matched to the normative profile because its channel names did not overlap with the cohort, it contained missing samples, or it was written as .set + .fdt because of its size. Section 15 lists these notes.

The button on the right downloads this recording's output: a single file (Download recording_sane.edf), or a zip when the format has several files (Download BrainVision bundle (.zip)).

Summary cards

CardHow to read it
θ/β biomarker deviationHow far this recording's theta/beta ratio (log scale, averaged over channels) is from the reference, before and after. Lower is better; 0 means the biomarker now equals the reference.
Spatial fingerprintHow far the channel-to-channel correlations are from the reference, averaged over bands. Lower is better. When spatial alignment was off, the card says so, and the two numbers stay close, as intended.
Trait Leakage Index ΛHow identifiable subjects are from their band-power features across the whole cohort, from 0 (cannot tell subjects apart) to 1 (fully identifiable). Lower is better. It needs at least two subjects who share channel names; otherwise the card explains why it is missing.
Brain dynamics keptHow closely the output follows the input within each band, measured on clean signal. 1 means the moment-to-moment activity is unchanged apart from the intended rescaling of each band. Higher is better. Waveform similarity, the plain correlation of the raw traces, is given underneath.

11The signal viewer

The viewer shows the recording itself, input and output, with every channel. It is the place to check with your own eyes that the brain activity is still there.

Toolbar

View modes

Bands, channel groups and scale

Reading values and selecting a channel

Hover over any trace to read its values. Click a trace to select that channel: its row is highlighted, its label turns indigo, and the Spectrum tab switches to that channel. Click it again to clear the selection.

Timeline and moving through the recording

The strip under the plots shows the whole recording: the overall signal level of the input (amber) and output (teal), events as ticks, and the current window as a shaded box.

  • Click anywhere on the timeline to jump there, or drag along it to scrub.
  • The ‹ and › buttons move back or forward by one window.
  • The ← and → arrow keys do the same, as long as the cursor is not in a text box or a menu.
  • The line next to the buttons reads, for example, 0 s – 10 s of 1:00 · 66 channels · 250 Hz.
  • The legend on the right repeats the colours: input, SANE output, visible difference, events.

Difference strip and difference graph

When a channel is selected, a strip appears above the traces. It says for how long the input and the output can be told apart in this window, lists the longest time spans and gives the time of the largest gap. Two traces count as apart when they are at least 1.5 pixels from each other at the current amplitude scale, so the answer changes with − and +. A dense 64-channel view often shows no separation until you amplify it; that is correct, not a fault.

The panel Difference timestamps by channel, under the timeline, shows the same time spans for every channel in the window. Its first line says how many channels differ and which one differs most. It follows the window, band, channel group, scale and Events settings of the viewer. Two buttons next to the title choose how it is drawn.

ViewHow to read it

A pink dot marks the largest gap of each time span, and the dashed line is the gap that becomes visible at the current scale. Hover over a dot to read its channel, time, gap and span. 12Analysis tabs

Below the viewer, five tabs measure what SANE changed in the selected recording. Click a tab name to switch.

Spectrum

The chart shows the power spectrum in decibels, input in amber and output in teal. The theta and beta bands, which form the biomarker, are shaded violet. Outside 1–45 Hz the two curves match when Keep content outside 1–45 Hz was on.

The Channel menu shows the mean of all EEG channels (default) or any single channel. Clicking a trace in the viewer also picks it here. The three cards give, for that selection, the log theta/beta ratio, the relative theta power and the relative beta power: input, then output, with the reference value underneath.

Band power

The left chart shows each band's share of the total power, averaged over channels, for the input, the output and the reference. The output bars should match the reference bars. The right chart shows every EEG channel's theta/beta deviation from the reference, as a pair of bars: input in amber, output in teal. Output deviations collapse onto the zero line.

Topography

Three head maps, seen from above with the nose at the top, show how a measure is spread over the scalp: Input, SANE output and Reference. White dots are electrodes. The output map should look like the reference map.

The Map menu chooses the measure: theta/beta ratio (log, default), or the relative power of delta, theta, alpha, beta or gamma. All three maps share one colour scale, shown underneath with its range. The note under the scale says how many channels have a known position. Channels without one are left off the maps.

Spatial fingerprint

Each square is a channel-by-channel correlation matrix: every row and column is one EEG channel, and the colour shows how strongly two channels move together in the chosen band, from −1 (blue, opposite) through 0 (white) to +1 (red, together). The three squares are the input, the SANE output and the reference.

The Band buttons choose delta, theta, alpha (default), beta or gamma. The distance numbers above the first two squares say how far each one is from the reference: the input distance is the subject's spatial fingerprint, and the output distance shows how much of it is left. With spatial alignment off, the two distances stay similar, as intended.

Privacy report

The report covers the whole session, not only the selected recording. The four cards at the top:

CardMeaning
Subjects / recordingsHow many different subject IDs and recordings were processed, and the strength α used.
θ/β between-subject varianceHow much the theta/beta biomarker still varies between subjects, before and after, and the percentage reduction. When the variance is close to zero, no threshold on this biomarker can tell patients from controls. Needs at least two subjects.
Trait Leakage Index ΛThe same index as the summary card: subject identifiability from band-power features, before and after.
Adaptive biomarker attackerA model that tries to recover each subject's theta/beta from the output, trained on all the other subjects. ρ is the correlation between its guesses and the truth: close to 0 means the attack fails. Needs at least five subjects.

The θ/β per subject table lists each subject's log theta/beta ratio on the channels all subjects share: input, output and the change. In a cohort, the output values should be almost equal.

The Recordings table has one row per recording:

ColumnMeaning
ReferenceThe reference used. For a cohort, the percentage of this recording's channels that other subjects share.
Fit windowsThe share of the recording's 4-second windows used to measure it. Windows with artifacts or missing samples are left out.
FingerprintSpatial fingerprint distance, input → output.
Power deviationThe typical difference between each channel's band power and the reference, on a log scale, input → output. 0 means every band of every channel sits on the reference.
Dynamics keptBrain dynamics kept, as on the summary card. Hover over the number to see it for each band.
WaveformPlain correlation between input and output traces on clean signal.
EventsNumber of events, the same in input and output.
OutputThe names of the files written for this recording.

The Scope box restates what SANE neutralizes and what it does not. Export report (JSON) downloads the full report as SANE_REPORT.json (section 13).

13Your output files

Names

Each output keeps the input name with _sane added: sub-002_task-rest_eeg.edf becomes sub-002_task-rest_eeg_sane.edf. FIF outputs end in _sane_raw.fif, following the MNE naming convention. You can therefore keep processed files next to the originals without overwriting anything.

How each format is written

FormatHow the output is made
EDF, BDFSANE Studio edits a copy of your uploaded file and replaces only the samples of the processed EEG channels. Labels, units, filter settings and per-channel sampling rates are kept, and every other channel stays bit-identical. Only the physical range of processed channels and, if you chose to, the personal fields change.
BrainVisionThe .vhdr and .vmrk files are copied as uploaded; only the file references inside them are updated to the new names. The .eeg data keeps its number format, channel order and resolution. (If processed values no longer fit a 16-bit integer file, it is saved as 32-bit floating point instead, and the header says so.) Every marker is kept exactly.
EEGLABA new .set is written with the channel names, positions and events. A .set + .fdt upload comes back as .set + .fdt. A single .set comes back as a single compressed .set, about the size of the upload, unless the data exceed 2 GB, in which case it is written as .set + .fdt (a note says so).
FIFWritten with MNE. MEG and all other channels are kept. Outputs over 2 GB are split into numbered parts automatically.

What is guaranteed to be the same

  • Channel names and order, sampling rate and number of samples.
  • Every event or annotation, with the same time and label.
  • Every non-EEG channel: EOG, ECG, EMG, triggers, sensors, MEG.
  • Missing samples. Gaps stored as missing values (NaN) are still missing in the output, in the same places.

The report file

SANE_REPORT.json is in the Download all zip, and also comes from Export report (JSON). It holds everything shown on the Results screen in machine-readable form: the settings used (alpha, bands), one entry per recording under recordings (reference, biomarkers before and after, fingerprint, power deviation, dynamics per band, fit windows, notes, output files), and the cohort measures under cohort (variance reduction, Trait Leakage Index, attacker results). Keep it with your processed data as a record of what was done.

14Privacy and data handling

  • Every upload gets its own session. Files from one session are never visible in another.
  • Sessions are deleted automatically 60 minutes after you last used them. The top bar shows the time left.
  • New session deletes everything immediately: uploads, working files and outputs.
  • Files are used only to produce your output. Nothing is kept for any other purpose.
  • Personal header fields are stripped by default (section 8).
  • When you run SANE Studio on your own computer, your data never leaves it. Working files go to the folder set by SANE_DATA_DIR (section 17).
LimitsSANE Studio removes subject-level spectral and spatial biomarkers. It does not remove every individual trait. File names, the folder structure of a dataset, and information inside events (for example a label containing a name) are not changed. Check these yourself before sharing data.

Phones and tablets

SANE Studio works on small screens. The layout stacks into one column, and wide tables scroll sideways inside their own box. For reviewing many channels, a laptop or desktop screen is much more comfortable.

18Glossary

Band
A frequency range of the EEG: delta (δ) 1–4 Hz, theta (θ) 4–8 Hz, alpha (α) 8–13 Hz, beta (β) 13–30 Hz, gamma (γ) 30–45 Hz.
Band power
How much signal a channel has in a band, averaged over the recording.
Biomarker
A measurable property of the signal that is linked to a condition. The theta/beta ratio, for example, is often raised in ADHD and some other conditions.
Brain dynamics kept
How closely the output follows the input from moment to moment within each band. 1 means unchanged apart from intended scaling.
Cohort
The group of subjects uploaded together. Its average is the cohort reference.
Companion file
A file that belongs to a recording's header file: the .vmrk and .eeg of a BrainVision .vhdr, or the .fdt of an EEGLAB .set.
Continuous recording
A recording kept as one uninterrupted stretch of data, as opposed to an epoched file cut into trials.
Fit windows
The clean 4-second stretches of a recording used to measure it.
Normative profile
The built-in typical spectral shape used as the reference when there is no cohort.
Pass-through channel
A channel SANE does not change, such as EOG, ECG or a trigger. Also called an auxiliary channel.
Reference
The profile every subject is moved toward: the cohort average or the normative profile.
Session
One upload and everything made from it. It is deleted after 60 minutes without use.
Spatial fingerprint
The pattern of how a person's EEG channels move together. It can identify a person and can carry disease information.
Strength α
How far each subject's spectral profile moves toward the reference, from 0 (not at all) to 1 (all the way).
Spatial alignment
How far each subject's spatial fingerprint moves toward the reference, from 0 to 1.
Theta/beta ratio
Theta power divided by beta power, shown on a log scale. 0 means equal power in both bands.
Trait Leakage Index Λ
How well subjects can be told apart from their band-power features, from 0 (not at all) to 1 (fully).
